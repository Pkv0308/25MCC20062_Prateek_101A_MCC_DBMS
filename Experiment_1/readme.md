# Experiment 1

## Aim
```
This experiment aims to design and implement a sample database syste using DDL, DML, and DCL commands.
This includes database creation, data manipulation, schema modification, and role-based access control to ensure data integrity and security.
```
## Objective
```
The objective of this experiment is to gain practical experience in implementing DDL, DML, and DCL operations in a real-life environment
```

## Experiment Steps

```
Experiment steps include:

1. creating tables using the create table command
2. inserting data into the table using the insert command
3. applying update and delete operations on the table
4. creating users and granting privileges and explicitly revoking certain privileges 
5. modifying the table schema to remove foreign key constraint
```
