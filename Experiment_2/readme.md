# Experiment 2

## Aim
```
The aim of this experiment is to implement and analyze SQL SELECT queries using filtering, sorting, grouping, and aggregation concepts for efficient data retrieval and analytical reporting.
```

## Objective
```
1. To retrieve specific data using filtering conditions
2. To sort query results using single and multiple attributes
3. To perform aggregation using grouping techniques
4. To apply conditions on aggregated data
5. To understand real‑world analytical queries
```
## Experiment Steps
```
Experiment steps include:

1. creating tables using the create table command
2. inserting data into the table using the insert command
3. retrieving data based on filters (conditions)
4. sorting the retrieved data: sorting according to one attribute and sorting according to multiple attributes (priority sorting)
5. retrieving grouped data with aggregate functions
6. retrieving grouped data with aggregate function matching certain conditions (having clause)
```
